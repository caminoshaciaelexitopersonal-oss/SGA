## 🎯 Common tasks

### Create a new skill
```
/skill-creator-pro Create a skill for [what you want to do]
Details:
- Input: [what users provide]
- Output: [what you deliver]
- Tools: [tools used, if any]
```

→ Get back: Complete SKILL.md file

### Improve an existing skill
```
/skill-creator-pro Improve [skill-name]
Problems:
- [Issue 1]
- [Issue 2]
```

→ Get back: Updated SKILL.md with fixes

### Convert a workflow
```
/skill-creator-pro Turn this into a skill:
I do:
1. [Step 1]
2. [Step 2]
3. [Step 3]

Input: [What I start with]
Output: [What I end with]
Tools: [Tools used]
```

→ Get back: Complete SKILL.md for your workflow
