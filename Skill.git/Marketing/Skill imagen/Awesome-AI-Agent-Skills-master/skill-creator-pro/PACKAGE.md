## 💾 Installation (all platforms)

### Claude (Web, Desktop, API)
1. Copy `SKILL.md` full text
2. Paste into chat
3. Use: `/skill-creator-pro [task]`

### OpenCode
1. Create: `~/.agent-skills/skill-creator-pro/`
2. Copy `SKILL.md` to folder
3. Use: `/skill-creator-pro [task]`

### Agent Skills
1. Create: `~/.skills/skill-creator-pro/`
2. Copy `SKILL.md` to folder
3. Use: `/skill-creator-pro [task]`

### Other SKILL.md systems
1. Place `SKILL.md` in your skills directory
2. Reference by name: `skill-creator-pro`
3. Use with your platform's trigger syntax
