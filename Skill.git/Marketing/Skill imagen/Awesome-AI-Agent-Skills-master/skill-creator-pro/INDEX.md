## ✅ Quality you'll receive

Every skill from skill-creator-pro includes:

| Element | What it means |
|---------|--------------|
| **Clear name** | Lowercase, hyphenated, specific (e.g., `seo-audit-basic` not `helper`) |
| **Trigger description** | Explains when to use it + example phrases |
| **Purpose** | What the skill does in 1-2 sentences |
| **When to use** | Situations and user phrases that trigger it |
| **Inputs needed** | What the user should provide |
| **Workflow** | Numbered, operational steps (not just advice) |
| **Output format** | Exact structure shown with examples |
| **Rules** | Key behaviors that must always happen |
| **Avoid** | Mistakes to prevent |
| **Quality checklist** | Before final delivery ("done" criteria) |
| **Test prompts** | 3-7 examples you can use to verify it works |

## 💡 Pro tips

### Tip 1: Be specific about output

❌ **Don't say:** "Write a report"  
✅ **Do say:** "Markdown report with Title, Key Findings (3 bullets), Recommendations (5 numbered items), Next Steps"

### Tip 2: Show an example

If you have an example of what you want, share it. Skills improve with references.

### Tip 3: Use the test prompts

Don't just create a skill and assume it works. Run the included test prompts and see if results match what you expected.

### Tip 4: Improve based on real failures

If a skill doesn't work as expected, tell it exactly what went wrong. It will add a rule to prevent that failure next time.

### Tip 5: Keep skills narrow

A skill that does one thing well beats a skill that tries to do everything. Narrow scope = better results.

## 🆘 Troubleshooting

| Issue | Solution |
|-------|----------|
| Skill not loading | Check that SKILL.md is in right folder, or paste full contents into chat |
| Vague results | Be more specific about output format and constraints |
| Test prompts fail | Run the test and compare output to expected result, ask skill to fix itself |
| Too many edge cases | Your skill might be too broad. Narrow the scope and split into multiple skills |
| Hard to trigger | Improve the description in frontmatter with user phrases |
