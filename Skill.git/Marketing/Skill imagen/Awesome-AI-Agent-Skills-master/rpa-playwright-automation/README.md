# 🚀 rpa-playwright-automation

Automatizador Robótico UI. Crea bots anti-frágiles con Playwright/Puppeteer para extraer datos o ejecutar tareas en sitios cerrados (Single Page Apps) que no tienen API.

## 🎯 About
This is an autonomous AI Agent Skill. It acts as a strict operational guideline for AI assistants.

## 🛠️ How to use
Add this folder to your agent's skills directory (e.g., .codex/skills).
