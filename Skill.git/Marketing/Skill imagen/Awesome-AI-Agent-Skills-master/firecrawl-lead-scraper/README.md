# 🚀 firecrawl-lead-scraper

Find, scrape, qualify, and export public business leads. This skill is universal and works with any available web search, crawling, and scraping tool (including Scrapling, Firecrawl, open-source tools like Crawl4AI, Scrapy, Puppeteer, or built-in agent capabilities). Use when the user wants to search businesses by niche, city, country, service, or ideal customer profile, extract public contact and website data, detect website improvement opportunities, and generate CSV, JSON, Markdown lead lists, and a self-contained HTML report without spam or private data collection.

## 🎯 About
This is an autonomous AI Agent Skill. It acts as a strict operational guideline for AI assistants.

## 🛠️ How to use
Add this folder to your agent's skills directory (e.g., .codex/skills).
