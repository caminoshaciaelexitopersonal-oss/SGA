# 🚀 proposal-generator

Generador maestro de propuestas comerciales B2B y SOWs. Estructura precios, alcance estricto (Scope of Work), valor psicológico y cronogramas para cierres altos (Win Rate).

## 🎯 About
This is an autonomous AI Agent Skill. It acts as a strict operational guideline for AI assistants.

## 🛠️ How to use
Add this folder to your agent's skills directory (e.g., .codex/skills).
