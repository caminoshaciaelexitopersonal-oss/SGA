# 🚀 model-augmenter

Use when any agent or coding assistant must produce stronger, more reliable results with ANY model — especially small, fast, preview, lite, local, uncensored, or non-reasoning models. Trigger on: "make this model think better", "serve any model", "global reasoning", "be more rigorous", "do it perfectly", "reduce hallucinations", "hazlo perfecto", "sirva para cualquier modelo", "implementalo global", or when the task is complex, risky, ambiguous, multi-step, or requires verification. This skill does NOT change model weights or provider APIs. It transforms the PROCESS around the model to extract maximum quality from any capability level.

## 🎯 About
This is an autonomous AI Agent Skill. It acts as a strict operational guideline for AI assistants.

## 🛠️ How to use
Add this folder to your agent's skills directory (e.g., .codex/skills).
