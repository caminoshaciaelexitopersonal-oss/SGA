# 🚀 billion-dollar-ai-team

Advisory marketing and sales skill that simulates six operator archetypes inspired by Alex Hormozi, Russell Brunson, Dan Kennedy, Jordan Belfort, Seth Godin, and Gary Vee. Use when auditing an offer, price, landing page, funnel, launch plan, sales call, email sequence, positioning, brand narrative, content strategy, or broader go-to-market decision. Also use when the user asks what one of these advisors would do, wants a panel review, or needs a blunt operator diagnosis instead of generic brainstorming.

## 🎯 About
This is an autonomous AI Agent Skill. It acts as a strict operational guideline for AI assistants.

## 🛠️ How to use
Add this folder to your agent's skills directory (e.g., .codex/skills).
