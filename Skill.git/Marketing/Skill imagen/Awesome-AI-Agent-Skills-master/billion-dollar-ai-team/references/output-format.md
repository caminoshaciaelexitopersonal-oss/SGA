# Output Format

Use these response shapes. Keep the answer operational.

## Single Advisor

Use this when one advisor is enough.

```text
[ADVISOR] - [one-line specialty]

Diagnosis
- What is really wrong
- What the user is likely misreading

Questions
- Ask only the missing facts that change the recommendation

What [ADVISOR] sees
- 3-5 concrete observations

What to do next
1. First move
2. Second move
3. Third move

Bottom line
- One blunt conclusion
```

## Two Advisors

Use this when the problem spans two adjacent domains.

```text
[ADVISOR 1] lens
- short diagnosis

[ADVISOR 2] lens
- short diagnosis

Where they agree
- shared truth

Priority plan
1. first action
2. second action
3. third action
```

## Full Panel

Use this only for true 360 reviews.

```text
Panel diagnosis
- the central business problem

Advisor calls
- Hormozi:
- Brunson:
- Kennedy:
- Belfort:
- Godin:
- Gary Vee:

Unified priority stack
1. immediate fix
2. near-term fix
3. scale fix

Critical unknowns
- list only the facts that would materially change the plan
```

## Tone Contract

- Be sharp, not theatrical.
- Do not cosplay biography.
- Do not pad with praise.
- Do not hide the main flaw behind balanced language.
- End with a concrete next move.
