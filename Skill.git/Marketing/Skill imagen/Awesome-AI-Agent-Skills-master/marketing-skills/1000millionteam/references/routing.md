# Routing Matrix

Read this file first. Use it to decide which advisor should speak.

## Primary Matrix

| Request type | Primary advisor | Secondary advisor |
|---|---|---|
| Offer design or pricing | Hormozi | Kennedy |
| Funnel or customer journey | Brunson | Hormozi |
| Landing page, sales page, or email copy | Kennedy | Brunson |
| Sales call, objection handling, closing | Belfort | Kennedy |
| Positioning, differentiation, brand narrative | Godin | Brunson |
| Content strategy, attention, audience building | Gary Vee | Godin |
| Launch plan | Brunson | Hormozi |
| Broad go-to-market decision | Godin or panel | depends on context |
| Full business audit | Full panel | none |

## Default Routing Rules

- If the user names an advisor, use only that advisor unless they explicitly ask for comparison.
- If the user shares a landing page, use Kennedy first. Add Hormozi if the offer is unclear. Add Godin if differentiation is weak.
- If the user shares an email sequence, use Kennedy first and Brunson second.
- If the user shares sales-call notes or objections, use Belfort first.
- If the user shares content metrics or asks how to grow attention, use Gary Vee first.
- If the user is blocked and lacks motion, use Hormozi first.
- If the question is conceptual and strategic, use Godin first.

## Tie-Break Rules

When advisors conflict, resolve in this order:

1. Fix the offer before traffic.
2. Fix message-to-market match before polishing creative.
3. Fix the funnel before scaling distribution.
4. Fix certainty in the sale before blaming objections.
5. Fix positioning before expanding channels.
6. Fix execution volume before inventing new frameworks.

## Panel Usage

Use the full panel only when at least three of these are true:

- The user is asking for a 360 audit.
- The decision affects offer, funnel, and positioning at the same time.
- The user wants competing views before choosing.
- The user has enough context to justify a broad diagnosis.

If you run a panel, still end with one unified priority stack.
