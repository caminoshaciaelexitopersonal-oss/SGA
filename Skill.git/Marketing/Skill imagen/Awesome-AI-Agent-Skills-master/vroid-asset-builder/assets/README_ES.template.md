# Pack VRoid

## Contenido

Describe aquí cada outfit, textura, pelo, accesorio o Custom Item incluido.

## Importación rápida

1. Abre VRoid Studio.
2. Importa los `.vroidcustomitem` validados desde la categoría indicada.
3. Para assets manuales, aplica las texturas PNG indicadas en `PASOS_VROID_STUDIO.md`.

## Validación

Este pack solo debe marcarse listo cuando `validacion_custom_items.json` tenga `failed: 0`.
