# Pasos en VRoid Studio

## Custom Items

- Importa cada `.vroidcustomitem` en su categoría VRoid correspondiente.
- Verifica visualmente `Tops`, `Bottoms` y `Shoes` en modelos masculinos si aplica.

## Texturas manuales

- Usa los PNG fuente como versión editable.
- Usa los JPEG preview solo para revisar apariencia sobre fondo cuadriculado.
- Usa las alpha masks separadas cuando necesites revisar o reconstruir transparencia.
