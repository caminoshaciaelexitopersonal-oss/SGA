2. ARQUITECTURA GENERAL DEL MONOREPOSITORIO
-------------------------------------------------------------------------------
El monorepositorio contiene 6 componentes principales y 5 utilidades/subproyectos:
1. SGA-CD-WEB.git: SPA en HTML5/JS ES6 + CSS3 Vanguard con Service Worker PWA v2.
2. SGA-CD-FASTAPI-BACKEND: API RESTful en Python/FastAPI con SQLAlchemy 2.0 y Pydantic.
3. SGA-CD-APP.git: Aplicación de Escritorio en Python con Flet framework y SQLite local (`local_sga.db`).
4. SGA-CD-APK.git: Aplicación Móvil en Python con Flet framework y SQLite local.
5. SGA-CD-DB.git: Migraciones de base de datos relacional gestionadas por Alembic (9 revisiones).
6. Skill.git: Design System, Tokens, Animaciones GSAP/Lenis y Guías UI/UX Dark Metallic Blue (60-30-10).
7. Submódulos Auxiliares: `audittor/` (anti-slop, graphify), `Soup/`, `fish-speech/`, `OpenJarvis/`, `verificaciones/`.

6. REGISTRO DE HALLAZGOS Y LIMITACIONES DEL ENTORNO (H-01 a H-03)
-------------------------------------------------------------------------------
1. H-01 [Media / Media Impacto]: Ausencia de paquetes global de FastAPI/SQLAlchemy en entorno de ejecución pip por defecto. Las pruebas puras corren gracias a las capas de compatibilidad/fallback.
2. H-02 [Baja / Medio Impacto]: Microservicios externos de IA (Colibrí 8080, Open Gen AI 3000, SkyReels 8090) inactivos en sandbox (`Connection refused`), activando los fallbacks del router.
3. H-03 [Media / Alto Impacto]: Daemon de PostgreSQL y `psql` ausentes en la imagen sandbox local; la persistencia física live de PostgreSQL requiere el aprovisionamiento de un servidor de base de datos externo.
